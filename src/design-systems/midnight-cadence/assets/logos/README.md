# Logos

The Halyard mark: an A-frame of two strokes with an amber crossbar.

- `halyard-mark-on-dark.svg`: strokes in `hy-fg` dark value (#eceef2), crossbar in `hy-signal` (#f2b66d). Use on dark surfaces.
- `halyard-mark-on-light.svg`: strokes #16181d, crossbar #b8711a. Use on light surfaces.
- The wordmark is the mark plus "Halyard" set in Geist 600 at -0.02em tracking, 10px gap. In code use `<Logo />` or `<LogoMark />`, which follow the theme automatically.
- Minimum size 16px. Keep clear space equal to the crossbar length on every side. Never recolour the crossbar to anything but the signal accent.
