# Card

A bordered surface that groups one idea: a feature, a plan, an integration, a cycle.

- `spotlight` (on by default) adds a soft glow under the cursor and lights the border nearby in `hy-signal`.
- `highlighted` marks the one recommended item in a set (an amber border and faint top tint).
- `interactive` lifts 2px on hover for clickable cards.
- Cards in a row share padding and baselines; let content set the height.
