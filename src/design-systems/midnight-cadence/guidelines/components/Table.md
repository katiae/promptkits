# Table

A native table styled to the system, inside a bordered panel that scrolls sideways on small screens.

- Header row sits on `hy-bg-raise` and stays visible while scrolling.
- Group rows (`TableGroupRow`) use the mono eyebrow style.
- `TableCheck` renders ✓ in `hy-fg` and — in `hy-fg-3`, each with an accessible label.
- Numbers use tabular figures.
