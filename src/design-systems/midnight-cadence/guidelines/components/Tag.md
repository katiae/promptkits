# Tag

A short label for a category or state, one or two words.

- `neutral` for categories (Bug, Feature). Tones only mean status: `signal` live/new, `ok` in review, `info` done, `danger` blocked.
- `solid` for one high-emphasis label per view, like "New" in an announcement pill.
- `dot` adds a leading dot in the tone colour; use it in lists where the colour carries meaning.
