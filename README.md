# Promptkits

I want to build a directory/website, similar to mobbin, but instead of having screenshots for how things look like, I want it to be a place with websites and apps, and showing a prompt on how to build those. You know, when you want to build something but haven't fully used ai yet, or you have but don't know how to achieve certain look or UX, so for example I want to know "how to build" the website from Cohere, I go, I see how it's been recreated by ai, I can interact with it on the demo, and then I can click to view the prompt used/needed to build that
